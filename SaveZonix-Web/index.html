Frequently Asked Questions

Why does SaveZonix download faster than standard tools?
SaveZonix is built in native C# .NET. Instead of pulling an entire video sequentially through one socket, it splits the media file into up to 64 discrete byte-range chunks fetched simultaneously over parallel TCP connections, saturating your internet speed.
How does the uBlock Origin ad shield work?
SaveZonix uses the official json-prune scriptlet architecture from uBlock Origin. It prunes adPlacements and playerAds directly from player API payloads before video initialization. Because no ads are scheduled, videos play at strictly normal 1.0x speed without buffer crashes or fast-forwarding bugs.
How do I install the Chrome Companion Extension?
Download SaveZonix-Extension.zip above, unzip the folder, open chrome://extensions in Chrome or Edge, enable "Developer mode" in the top right, and click "Load unpacked" selecting the unzipped folder.
Where are downloaded videos stored?
All downloaded media files are saved directly in your Windows Downloads folder. You can configure a custom destination folder at any time in the desktop application settings.
